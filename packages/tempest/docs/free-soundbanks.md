# DSI / Sequential Tempest - Free Soundbanks & Patch Collections

A curated list of free (and notable pay-what-you-want) .syx patch collections, soundbanks, and community resources for the Dave Smith Instruments / Sequential Tempest drum machine.

> **Loading SysEx files:** Use [SysEx Librarian](https://www.snoize.com/sysexlibrarian/) (Mac) or [MIDI-OX](http://www.midiox.com/) (Windows), or Elektron's C6 utility. Connect via USB or MIDI. Set Tempest's `MIDI: SysEx IN+OUT Cable` to match your connection type.

---

## Official Factory Sounds

### Sequential Factory Program Banks
- **URL:** https://sequential.com/support/download/tempest-sounds/
- **Content:** Two complete factory sound sets:
  - **OS 1.4 sound set** (requires OS 1.4+)
  - **Original sound set** (OS 1.0-1.3)
- **Format:** .syx project dumps
- **Notes:** Includes full installation instructions for Mac and Windows. The 1.4 sound set has a changed internal file format -- projects modified/saved on 1.4 will NOT be backwards-compatible with older OS versions. Back up first.

- **URL:** https://hardwarecore.wordpress.com/2015/06/01/dsi-tempest-soundset-hardwarecore-1/

  - 16 Bass Sounds
  - 16 Leads & Misc Sounds
  - 16 Bass Drums
- **Format:** Two .syx files: `HWC Lead, Effect, BD.syx` and `HWC Pads & Bass.syx` (32 sounds each, loads as one "Beat")
- **Notes:** Originally sold for $10, now completely free. All patches designed from the ground up using primarily analog oscillators. WAV previews also available on [Internet Archive](https://archive.org/details/HardwarecoreDSITempestSoundbankSamples).

### Leviathant's TR-606 & DR-110 Emulations
- **URL:** https://www.bitrotten.com/tempest/
- **Content:** Analog drum kit emulating TR-606 and DR-110 sounds, including:
  - Multiple iterations of kicks, snares, handclaps
  - Various approaches (self-oscillating filter, digital sine, sawtooth LFO claps, etc.)
- **Format:** .syx file (zip download with readme listing all sounds)
- **Notes:** Result of a full year of sound design work, using Visual Analyzer, oscilloscopes, and careful A/B comparison with original hardware (TR-606, DR-110). Donation-ware ($5 suggested). Widely praised in the community.

### Yorgos Arabatzis - Various Tempest Patches Collection

- **Content:** `Various Tempest Patches.zip` -- a comprehensive archive containing:

- **Notes:** This is the single most important community archive. When the old DSI Forum went down, Yorgos preserved all shared patches here. **Requires a free forum account to download.**

## Tips for Loading Patches

- **Mac:** Use [SysEx Librarian](https://www.snoize.com/sysexlibrarian/). Set "Pause between played messages" to 1 second in Preferences.
- **Windows:** Use [MIDI-OX](http://www.midiox.com/). Set buffer delays: 375ms between buffers, 1000ms after F7. Buffer size: 1024.
- **Cross-platform:** Elektron's C6 utility works well and is recommended by forum moderators.
- **Important:** The Tempest has a limit of **650 sound program locations**. Back up existing sounds before mass-loading new ones.
- **USB vs MIDI:** USB requires OS 1.2+. MIDI jacks work with any OS version.
- **OS 1.4 compatibility:** Sounds saved/exported on OS 1.4 are NOT backwards-compatible with older OS versions.
