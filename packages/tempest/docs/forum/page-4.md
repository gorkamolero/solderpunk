## Post 62: RobH
**Date:** October 27, 2017, 04:45:44 PM

Shared a polyphonic patch called "Pads of Patch" describing it as "a fairly simple patch but beautiful all the same." The patch includes:
- 3-note chord capability with room for additional notes
- Manual LFO adjustments to the VCA (voltage-controlled amplifier)
- Optional drum/synth layering possibilities
- A pan LFO that can be reassigned to VCA duties

Audio examples posted to SoundCloud. Attached patch file: "Pads of Patch.syx" (0.15 kB). The example included reverb processing but described it as minimal.
