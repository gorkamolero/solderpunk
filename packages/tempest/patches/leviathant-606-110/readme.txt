Leviathant Drums v1: x0x;110

Installation: The .SYX file contains a Tempest Beat. The beat includes 32 
sounds, and a demo pattern that hits most of the sounds. For details on how 
to transfer Sysex files, please see your Tempest manual. I open the file in 
MIDI-OX, which loads it into the "SysEx View and Scratchpad" window. I make 
sure I have my Tempest on and set as an Output port in Options>MIDI Devices, 
and then I click Command Window > Send Sysex. The screen on the Tempest should 
display a message about having received the beat. From there, you should be 
able to modify & save the beat and any of the individal sounds attached to it.
