# ZOIA / Euroburo — Video & Media Learning Resources

Curated, verified learning resources for the Empress ZOIA and ZOIA Euroburo grid-based modular pedal. Every entry below was confirmed via WebSearch and/or WebFetch to exist and to be about the ZOIA. Items that could not be confirmed were discarded.

Note on verification method: YouTube watch/playlist/channel pages serve a region consent wall to the fetch tool, so individual YouTube URLs could not be opened directly. Those entries are verified via WebSearch result metadata (exact title + channel + description + date returned by the search index), which is the authoritative source for "this video exists and is about X." Non-YouTube pages (blogs, reviews, MatrixSynth) were verified by direct WebFetch and that method is noted per entry.

## Notes & caveats

- **No dedicated paid course found.** Despite searching for Patreon / paid ZOIA courses, none surfaced. The ZOIA "course" ecosystem is effectively free: the official Empress playlist + Ron Cavagnaro's 8-part Quickstart (the famous beginner series) + Christopher Jacques's Module Rundown and Encyclopedia of CV playlists together form a complete free curriculum. Discarded the paid-course angle as unconfirmable.
- The ZOIA skill notes the r/ZOIA wiki/FAQ is **disabled**, so it is intentionally omitted as a broken resource.
- Several entries note exact firmware-era context (e.g., Granular tutorial on fw 1.03, S&H series on fw 2.x); module behavior may have shifted across firmware — cross-check against the live Module Index for current ranges.
