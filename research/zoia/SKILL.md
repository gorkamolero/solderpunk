# ZOIA / ZOIA Euroburo

Research source: `/Users/gorkolas/www/music/solderpunk/research/zoia/` (`claude.md`, `chatgpt.md`)

## What This Covers

- The grid-based modular operating model: modules, blocks, connections, pages, patches
- The hidden *behaviors* (not modules) that unlock the platform: connection-strength math, CV summing, starred params, Performance Mode, page import, Device Control
- Firmware version gems and compatibility traps (baseline **fw 5.32**)
- MIDI / CV / expression / Control Port mapping, including the device-level CC 60-63 remote map
- The ~90+ modules organized as a learning checklist across five categories
- Patch-design recipes with exact starter settings
- ZOIA-vs-Euroburo differences, the community-reverse-engineered .bin format, and the resource ecosystem

## Key Constraint

ZOIA is **not a knob panel** — it is a programmable grid. A *module* is a building block occupying one or more of the **40 buttons** on each **8×5 page**; each button is an input, output, or parameter, and each is either audio or CV ([manual](https://empresseffects.com/cdn/shop/files/ZOIA_User_Manual_rev02_web.pdf?v=9116714327727882529)). You patch by wiring outputs to inputs and dialing a **connection strength**. There is no real-time DAW automation surface and no general-purpose USB; patches/firmware/samples move via **microSD (FAT32 only)** and MIDI runs over **1/8" TRS Type A** ([manual](https://empresseffects.com/cdn/shop/files/ZOIA_User_Manual_rev02_web.pdf?v=9116714327727882529), [firmware page](https://empresseffects.com/blogs/support-zoia/updating-firmware-on-the-zoia-and-euroburo-latest-version)). Patch design is therefore equal parts module wiring, **interface design** (UI Buttons, Pixels, pages), and **CPU budgeting**.

## Quick Reference

- **Grid:** 40 buttons/page (8 cols × 5 rows); a patch holds up to **64 pages**; internal memory holds up to **64 patches**. Connections cross **pages** but never cross **patches** ([manual](https://empresseffects.com/cdn/shop/files/ZOIA_User_Manual_rev02_web.pdf?v=9116714327727882529))
- **Signals:** audio flows output→input; CV is normalized **0→1 or −1→1**; CV inputs can be biased even with nothing connected, audio inputs cannot ([manual](https://empresseffects.com/cdn/shop/files/ZOIA_User_Manual_rev02_web.pdf?v=9116714327727882529))
- **Encoder:** rotate = value; press+rotate = fine; **Shift+rotate = super-fine** (gesture set added in fw 2.40) ([changelog](https://cdn.shopify.com/s/files/1/0028/5462/files/zoia_changelog_74aa73a7-3b95-425b-ba10-baf85de31592.txt?v=1770216051))
- **Connections:** select two blocks (hold both on same page, or pick one then change pages) and dial strength; press encoder to toggle **% vs dB** display ([manual](https://empresseffects.com/cdn/shop/files/ZOIA_User_Manual_rev02_web.pdf?v=9116714327727882529))
- **Pitch scaling:** `0.1 CV = 1 octave`; 5th ≈ .058, 4th ≈ .042; drop pitch via CV Invert ([Tips doc](https://docs.google.com/document/u/0/d/1bDqMHjLc4GCYtf2yGNHgjkDqQJ6zrRVuCZohJdKkWWc/mobilebasic))
- **CV sample rate:** 1/64 of 48 kHz = **750 Hz** (one sample / 1.333 ms); bypassed latency 3.21 ms, +1.33 ms per audio module in series ([claude.md, Empress support])
- **Module count:** product/Euroburo pages now say **"over 90"**; long-standing marketing figure was **"80+"** — see Contradictions ([product page](https://empresseffects.com/products/zoia), [Euroburo](https://empresseffects.com/products/zoia-euroburo))

## Contradictions & Version Flags (read before quoting numbers)

- **Module count: "80+" vs "90+".** Historical figure is "80+"; current Empress product and Euroburo pages say "over 90." The module set grew via firmware (Sampler, Logic Gate, Reverse Delay, Univibe, etc.). The authoritative list is the live [Module Index spreadsheet](https://docs.google.com/spreadsheets/d/1a9q2OCo_Sd_IbWsH99wlFvjcTIN20e7wb5Qgn5fLxms/edit?usp=sharing) for your firmware ([claude.md](https://empresseffects.com/products/zoia)).
- **Firmware baseline: 5.00 vs 5.32.** The older `claude.md` treats **5.00** (Dec 10, 2024) as latest. The newer `chatgpt.md` documents through **5.32** (dated 2025-12-15). **Prefer 5.32** for any firmware/version fact ([changelog](https://cdn.shopify.com/s/files/1/0028/5462/files/zoia_changelog_74aa73a7-3b95-425b-ba10-baf85de31592.txt?v=1770216051)).
- **Stompswitch aux-mode hold time: 1 s vs 2 s.** The official ZOIA manual says hold **Bypass+Scroll ~1 second** to toggle the stompswitches between normal and auxiliary/custom-module duties; the community Tips doc and the Module Index row text say **~2 seconds**. In practice, hold until the indication changes — document as **"about 1-2 seconds"** ([manual](https://empresseffects.com/cdn/shop/files/ZOIA_User_Manual_rev02_web.pdf?v=9116714327727882529), [Tips doc](https://docs.google.com/document/u/0/d/1bDqMHjLc4GCYtf2yGNHgjkDqQJ6zrRVuCZohJdKkWWc/mobilebasic)).
- **Old community CSV ≠ firmware-5 list.** The sensai7 Cheatsheet CSV predates Sampler, Logic Gate, Reverse Delay, Univibe; use it for quick lookup, verify against the official sheet ([Cheatsheet CSV](https://raw.githubusercontent.com/sensai7/ZOIACheatsheet/master/zoiaCSV.csv)).
- **Sequencer patches saved on fw 4.20+ won't load on older firmware** (data footprint was reduced). Back up first; note firmware version when sharing sequencer patches ([changelog](https://cdn.shopify.com/s/files/1/0028/5462/files/zoia_changelog_74aa73a7-3b95-425b-ba10-baf85de31592.txt?v=1770216051)).
- **r/ZOIA wiki/FAQ is disabled** by mods — old FAQ links are stale; use subreddit search, the Tips doc, and Patchstorage/GitHub directly ([r/ZOIA FAQ](https://www.reddit.com/r/ZOIA/wiki/faq)).
- **Binary .bin format is reverse-engineered, not official** — Empress has stated they will not open it; field offsets are community-derived and the Go author flags uncertainty (patch-length size, module-name extraction) ([mdouchement](https://github.com/mdouchement/zoia)).

## Hidden Features Most Owners Miss

The biggest levers are **behaviors, not modules** ([Tips doc](https://docs.google.com/document/u/0/d/1bDqMHjLc4GCYtf2yGNHgjkDqQJ6zrRVuCZohJdKkWWc/mobilebasic)).

- **Multiplier as a CV VCA:** route a CV source and a Value module into a Multiplier; the Value becomes a remote/modulatable depth control (drive it from an LFO/ADSR) ([Tips doc](https://docs.google.com/document/u/0/d/1bDqMHjLc4GCYtf2yGNHgjkDqQJ6zrRVuCZohJdKkWWc/mobilebasic)).
- **ZOIA math (CV summing):** CV **sums at inputs** — positive values add, negative values (Value set −1→1, or CV Invert) subtract. **Connection strength < 100% divides, > 100% multiplies.** Routing one source into multiple inputs of a Multiplier gives exponents (Y×Y = Y²). Because CV sums, **offset cancellation** (Value + Sample&Hold + CV Invert + stompswitch) lets automation start from the current value instead of jumping ([Tips doc](https://docs.google.com/document/u/0/d/1bDqMHjLc4GCYtf2yGNHgjkDqQJ6zrRVuCZohJdKkWWc/mobilebasic)).
- **Min/maxing modulation:** bias the destination (or a Value) to set the modulation **minimum**; set connection strength to set the **range/max**. With a −1→1 LFO, bias = centerpoint, strength = spread ([Tips doc](https://docs.google.com/document/u/0/d/1bDqMHjLc4GCYtf2yGNHgjkDqQJ6zrRVuCZohJdKkWWc/mobilebasic)).
- **Logic gates without the Logic Gate module:** NOT = CV Invert + Value biased to 1; AND = Multiplier; OR = sum at a shared input; NAND = AND→NOT; NOR = OR→NOT; XOR/XNOR = multipliers + inverter/comparator; Comparator does max/min ([Tips doc](https://docs.google.com/document/u/0/d/1bDqMHjLc4GCYtf2yGNHgjkDqQJ6zrRVuCZohJdKkWWc/mobilebasic)).
- **Starred parameters = a hidden performance layer:** Star a selected param/connection to add it to the **Starred List** (Star with nothing selected opens the list). Star again on a starred item to assign **MIDI CC**, including a **"learn"** that grabs the next incoming CC. Trick: star a **Value module** as an intermediary so you can attenuate/invert the CC and send MIDI feedback back out ([manual](https://empresseffects.com/cdn/shop/files/ZOIA_User_Manual_rev02_web.pdf?v=9116714327727882529), [Tips doc](https://docs.google.com/document/u/0/d/1bDqMHjLc4GCYtf2yGNHgjkDqQJ6zrRVuCZohJdKkWWc/mobilebasic)).
- **Performance Mode (Shift+Back on home):** blocks new connections/deletes so you can't break a patch while playing; Back lights **magenta**. Added in fw 1.13. Build a front page of UI Buttons/Pixels/Values/starred controls, then enter it ([manual](https://empresseffects.com/cdn/shop/files/ZOIA_User_Manual_rev02_web.pdf?v=9116714327727882529), [changelog](https://cdn.shopify.com/s/files/1/0028/5462/files/zoia_changelog_74aa73a7-3b95-425b-ba10-baf85de31592.txt?v=1770216051)).
- **Page import = personal libraries:** import a page from another patch; connections within an imported page (and between pages imported together) are preserved. Maintain reusable utility pages — MIDI hub, tap-tempo, flexi-switch, quantizer, mixer/output ([manual](https://empresseffects.com/cdn/shop/files/ZOIA_User_Manual_rev02_web.pdf?v=9116714327727882529), [Utility Pages 1](https://patchstorage.com/utility-pages-1/)).
- **Device Control module (fw 2.20):** a CV-controlled interface module that controls the *device itself* — audio bypass, Performance Mode, stompswitch aux mode — in response to CV/MIDI/sequencers/UI. Underused because it looks like a utility ([changelog](https://cdn.shopify.com/s/files/1/0028/5462/files/zoia_changelog_74aa73a7-3b95-425b-ba10-baf85de31592.txt?v=1770216051)).
- **DSP Usage viewer (Config):** scrolls/highlights the first 64 modules — also a way to *find* hidden/overlapping modules. Keep live patches **under ~70% CPU**; prefer Reverb Lite over Plate/Hall ([claude.md], [Tips doc](https://docs.google.com/document/u/0/d/1bDqMHjLc4GCYtf2yGNHgjkDqQJ6zrRVuCZohJdKkWWc/mobilebasic)).
- **Multiple display readouts:** press encoder to cycle LFO rate Hz / seconds / BPM; Value raw vs note (A0–A10); connection strength % vs dB ([Tips doc](https://docs.google.com/document/u/0/d/1bDqMHjLc4GCYtf2yGNHgjkDqQJ6zrRVuCZohJdKkWWc/mobilebasic)).
- **"Old module" compatibility (fw 2.00):** older saved modules persist as versioned "old" variants so old patches don't break — two patches with the "same" module type may not behave identically ([changelog](https://cdn.shopify.com/s/files/1/0028/5462/files/zoia_changelog_74aa73a7-3b95-425b-ba10-baf85de31592.txt?v=1770216051)).
- **SD hygiene:** hidden macOS/Spotlight files can hang ZOIA on "waveform updating" (fw 3.0) and even block boot; show hidden files and delete them before use ([support article](https://empresseffects.com/blogs/support-zoia/zoia-gets-stuck-on-waveform-updating-when-running-firmware-3-0)).

## Firmware Notes & Version Gems (baseline fw 5.32)

**Update safety:** back up via **Config → Patches to SD Card** first; copy `eezoXXXX.bin` to the FAT32 SD root; pins **up** on ZOIA, **down** on Euroburo; no SD extenders; update can take ~3 min with up to 5 min blank screen; delete the firmware .bin after boot (or use "Hide Firmware?") ([firmware page](https://empresseffects.com/blogs/support-zoia/updating-firmware-on-the-zoia-and-euroburo-latest-version), [changelog](https://cdn.shopify.com/s/files/1/0028/5462/files/zoia_changelog_74aa73a7-3b95-425b-ba10-baf85de31592.txt?v=1770216051)).

- **5.32** (2025-12-15): fixed bank-preset UI bypass, startup hang when start patch = 0, startup bypass-state issues.
- **5.31:** fixed MIDI bug where **CC value 127 was not processed** — matters for controllers using 127 as "on".
- **5.30:** fixed CV Mixer bug; expanded **Granular** with **4 s and 16 s grain sizes**, grain params update at end of silence, density 0 = no output.
- **5.20 / 5.00:** introduced/finalized **Reverse Delay** and **Univibe** modules; **~14% CPU** improvement; new fw-5 factory patches (ZOIA-only; Euroburo downloads separately); Groovebox & Grand Piano need samples on SD.
- **4.20:** sequencer data footprint reduced — **patches with sequencers saved on ≥4.20 won't load on older firmware**.
- **4.00:** Sampler workflow + big Sequencer update (CV step, **CV ramp** output, key input, sequencer **pages up to 256 steps**); sample-rate converter.
- **3.00 / 3.01:** Sampler (beta) + Logic Gate; extra WAV support; single-patch import/export.
- **2.60:** Quantizer "extended" → **40+ scales**. **2.40:** encoder fine/super-fine gestures. **2.30:** MIDI CC Setup; SV Filter instant-frequency option; Stompswitch module removed from Euroburo menu. **2.20:** Euroburo compatibility merged, **Device Control**, "Euro Modules" page, page-left/right pulses. **2.10:** real **Undo** stack + on-screen undo-level counter. **2.00:** ~24% CPU reduction, CV Mixer/attenuverter, ADSR rework, Sample&Hold track-and-hold.
- **1.13:** MIDI Clock Out (24 PPQN), MIDI Pitch Bend, Tap to CV, round-robin MIDI, Clock Divider 1-32 divisor/dividend, linear LFO/ADSR CV, **Performance Mode**, screensaver. **1.10:** Extended Colours, MIDI Consume, CV Loop max 16 s.
- **Hardware note:** firmware **1.05 and lower won't run** on ZOIAs with serial ≈2000+ ([old firmware page](https://empresseffects.com/blogs/support-zoia/old-firmware-versions-for-the-zoia)).
- **Ceiling:** per [eclab/zoia](https://github.com/eclab/zoia), Empress has said the pedal is "basically out of firmware space" — major new features unlikely.

## MIDI / CV / Control Map

- **Physical MIDI:** 1/8" TRS **Type A** (listen on **TIP**, send on **RING**); same as Korg/Make Noise; optocoupler inside; try an active splitter if marginal wiring fails ([MIDI type](https://empresseffects.com/blogs/support-zoia/whats-the-midi-type-that-our-pedals-use), [troubleshooting](https://empresseffects.com/blogs/support-zoia/midi-is-not-working-with-zoia-but-works-with-everything-else)).
- **Program Change** selects patches **starting at 0** — offset external PC lists that start at 1 ([manual](https://empresseffects.com/cdn/shop/files/ZOIA_User_Manual_rev02_web.pdf?v=9116714327727882529)).
- **MIDI Consume (Config):** `some` (default — used MIDI consumed, rest passed) / `all` (nothing passed) / `none` (everything passed = thru/merge). Set to some/all to avoid feedback loops ([claude.md], [Tips doc](https://docs.google.com/document/u/0/d/1bDqMHjLc4GCYtf2yGNHgjkDqQJ6zrRVuCZohJdKkWWc/mobilebasic)).
- **Device-level CC remote map** (on the configured channel, separate from patch modules & starred params) ([MIDI CC article](https://empresseffects.com/blogs/support-zoia/controlling-the-zoia-and-euroburo-via-midi-cc-control-change-values)):
  - **CC 60** — bypass: 0 = bypass, 64 = toggle, 127 = engage
  - **CC 61** — button **press**; **CC 62** — button **release**. Value map: **0-39** = the 40 grid buttons, **40/41** = Page Left/Right, **42** = Back, **43** = Shift, **44/45** = Euroburo pushbuttons, **46-49** = CV inputs, **50-53** = CV outputs, **54/55** = audio inputs, **56/57** = audio outputs, **58** = headphone, **124/125/126** = right/middle/left stomp, **127** = rotary switch
  - **CC 63** — rotary movement: value − 64 = number of turns (65 = one CW step, 63 = one CCW step)
  - fw 4.00 reserved **CC 61-63** for buttons/stomps/rotary — revise old templates that used them for patch control
- **Starred-param MIDI learn:** Star → Star again → assign CC, or use "learn" for the next incoming CC. Prefer learning a **Value module** intermediary to attenuate/invert ([manual](https://empresseffects.com/cdn/shop/files/ZOIA_User_Manual_rev02_web.pdf?v=9116714327727882529)).
- **Control Port (pedal, ¼" TRS):** Config sets it to **MIDI / expression / CV / external switch**. CV mode = **0-5 V**. Expression pinout: **TIP = signal, RING = 3.3 V, SLEEVE = ground** — pedals wired with signal on the ring cram all travel into the first ~10%. When onboard MIDI ports are in use, Control Port can only **send** MIDI out ([manual](https://empresseffects.com/cdn/shop/files/ZOIA_User_Manual_rev02_web.pdf?v=9116714327727882529), [expression article](https://empresseffects.com/blogs/support-zoia/what-expression-pedals-can-i-use)). Smooth jumpy expression/CV through a **Slew Limiter**; record automation via Value → CV Looper ([Tips doc](https://docs.google.com/document/u/0/d/1bDqMHjLc4GCYtf2yGNHgjkDqQJ6zrRVuCZohJdKkWWc/mobilebasic)).
- **Euroburo CV:** 4 in + 4 out, each editable for **−5/+5 V, 0/5 V, or 0/10 V** plus normalized 0→1 / −1→1; eight dedicated CV buttons; **clock filters** (Schmitt-trigger) on CV inputs to clean noisy gates/triggers (engage via Shift + pencil icon to stop ADSR false-triggers); **CV transpose A→C** for C-to-C gear ([Euroburo manual](https://images.equipboard.com/uploads/item/manual/97410/empress-zoia-euroburo-manual.pdf), [Module Index](https://docs.google.com/spreadsheets/d/1a9q2OCo_Sd_IbWsH99wlFvjcTIN20e7wb5Qgn5fLxms/edit?usp=sharing)).
- **MIDI Notes In:** up to 8 voices; priority newest/oldest/highest/lowest/round-robin; greedy allocation; low/high note limits; note/gate/velocity/trigger outputs; range C-2 to A10. **MIDI Clock In** beat multipliers/dividers: 1, 2, 3, 4, 6, 12, 1/2, 1/3, 1/4, 1/6, 1/12 ([Module Index](https://docs.google.com/spreadsheets/d/1a9q2OCo_Sd_IbWsH99wlFvjcTIN20e7wb5Qgn5fLxms/edit?usp=sharing)).

## Module Categories (learning checklist)

Five groups; exact per-block ranges, options, and average DSP/CPU live in the [official Module Index spreadsheet](https://docs.google.com/spreadsheets/d/1a9q2OCo_Sd_IbWsH99wlFvjcTIN20e7wb5Qgn5fLxms/edit?usp=sharing) — cross-check it before publishing recipes or CPU budgets.

- **Interface / I/O:** Audio Input/Output, MIDI Notes In, MIDI CC In, MIDI Pressure, MIDI Clock In/Out, MIDI CC/PC/Note Out, MIDI Pitch Bend, Stompswitch, UI Button, Pixel, Pushbutton, Keyboard, Device Control, CPort Exp/CV In, CPort CV Out, Euroburo CV In/Out + integrated audio/CV/pushbutton/headphone blocks.
- **Analysis (audio→CV):** Onset Detector (peaks → trigger; easy to over-trigger — gate it first), Env Follower (level → CV; connection strength = sensitivity), Pitch Detector (pitch → note CV).
- **Audio:** Oscillator (sq/tri/saw/sine, FM, duty, upsampling), VCA, SV Filter (LP/HP/BP; fast coefficient changes), Multi-Filter (HP/LP/BP/bell/shelf; cleaner but CPU-heavy when modulated), Delay Line (100 ms-16 s, no dry/no repeats — feed back for repeats), Audio Panner/Balance/Mixer, Pitch Shifter, Inverter (+1 Buffer Delay for phase), In/Out Switch, Noise, Ring Modulator, Bit Crusher, Aliaser, Granular (grain size/position/density/texture/freeze; 4 s/16 s grains in fw 5.30), Looper, Sampler (beta fw 3.0+), Stereo Spread, Bit Modulator, Diffuser, All Pass, 1 Buffer Delay.
- **CV / control / logic / sequencing:** LFO, Sequencer (1-32 steps × up to 8 tracks; pages to 256 steps; CV step, CV ramp, key input), ADSR (linear-time option), Sample & Hold (track-and-hold), CV Invert/Rectify, Value, Trigger, CV Flip-Flop, CV Delay, CV Loop (16 s), CV Filter (rise/fall), Clock Divider (1-32), Comparator, In/Out Switch, Slew Limiter, Quantizer (40+ scales), Steps, Multiplier, Random (has "new value only on trigger" = built-in S&H), Rhythm, Tap to CV, Logic Gate (AND/OR/NOT/NOR/NAND/XOR/XNOR), CV Mixer, Attenuverter.
- **Prebuilt effects:** Tone Control EQ, Delay w/Mod, Ping Pong Delay, Reverse Delay (fw 5), OD & Distortion, Fuzz, Compressor, Gate, Plate/Hall/Room Reverb, Ghostverb, Reverb Lite (CPU-friendly), Phaser, Chorus, Vibrato, Flanger, Univibe (fw 5), Tremolo, Env Filter, Ring Modulator, Cabinet Sim. (Predelay is **missing** from reverbs — insert a Delay before the reverb to add it, per [eclab/zoia](https://github.com/eclab/zoia).)

## Patch-Design Recipes (exact starter settings)

All settings are starting points — confirm block names/ranges in the [Module Index](https://docs.google.com/spreadsheets/d/1a9q2OCo_Sd_IbWsH99wlFvjcTIN20e7wb5Qgn5fLxms/edit?usp=sharing). Community recipes from the [Tips doc](https://docs.google.com/document/u/0/d/1bDqMHjLc4GCYtf2yGNHgjkDqQJ6zrRVuCZohJdKkWWc/mobilebasic).

- **Mono subtractive voice:** MIDI Notes In (ch 1, 1 voice, priority newest) → note→Oscillator freq @100%, gate→ADSR gate @100%. Oscillator (saw/square) → SV Filter (LP, cutoff ~0.25, res 0.25-0.35) → VCA → Audio Output. ADSR (A 5 ms, D 150 ms, S 0.65, R 250 ms) → VCA level @100%. Optional: ADSR→cutoff @25-45% for sweep; note→cutoff @50-100% for keytracking.
- **Generative "Space Race":** Random CV → Quantizer (key of D) → Oscillator; a square LFO clocks Random for new notes; a fast LFO adds vibrato; multiple Sequencers feed an In Switch cycled by a "slow ass LFO"; everything into Hall Reverb ([Patchstorage](https://patchstorage.com/platform/zoia/)).
- **Granular freeze / "Harmonic Pixies":** Audio In → Granular → Out; momentary Stompswitch/Pushbutton → Granular freeze @100%; density & texture near max; grain size 200-400 ms (test 4 s/16 s on fw 5.30+); position 400-600 ms. For "Harmonic Pixies": 3 Granular instances, 8 grains each, max size/texture/density, detuned, each fed back on itself — **cap feedback ~−17 dB**. "Decepticon" near-dry trick: 8 grains, max grain size, min position, max density/texture.
- **CS-80 polysynth "ZS-40":** key-tracked filter @100%; shared filter/VCA **bipolar** envelope; ring mod with envelope-controlled frequency; 12 dB/oct via two stacked LPFs; ADSR A/D/R **linear**, 15 s max (.1 = 1.5 s) ([ZS-40](https://patchstorage.com/zs-40-a-polysynth-patch-inspired-by-a-legend/)).
- **Delay-line feedback network:** Audio In → Audio Balance dry; Audio In → Delay Line (350-600 ms delay; 20-80 ms predelay; 0-20 ms vibrato/chorus/flanger). Delay out → VCA (start ~25-35% / −12 to −9 dB, reduce if self-oscillating) → SV/Multi-Filter (LP 3-6 kHz, low res) → Delay in (= repeats). Delay out → Balance wet → Out.
- **Time-based effects from Delay Line:** Vibrato 0-20 ms + slow LFO, no dry; Chorus 10-30 ms dry+wet; Doubler ~35-45 ms; Flanger 0-10 ms + conservative feedback; Slapback 50-100 ms; Thru-zero flanger = two 2-10 ms lines with opposite bipolar LFO motion.
- **64 s delay / hold buffer:** four 16 s Delay Lines in series, last→first feedback VCA. Hold buffer: VCA1→Delay→Out, Delay→VCA2→Delay; latching stomp opens VCA1 to record, complement (Comparator/CV Switch) opens VCA2 to recirculate.
- **Low-pass gate:** Osc/Audio In → VCA → SV Filter LP → Out; one ADSR (A 1-5 ms, D 200-800 ms, S 0, R 100-400 ms) → VCA level @100% **and** → cutoff @40-70%; cutoff bias ~0.1-0.2, res 0.1-0.3.
- **Turing-machine sequencer:** 8× Sample & Hold chained, common clock; Random→CV Switch A, last S&H→CV Switch B, Value "mutation"→select (low = recirculate, high = inject random); S&H output → Quantizer → Oscillator freq.
- **Flexi-switch (momentary tap / latched hold):** momentary Stompswitch + ADSR (shortest A/D, Hold A/D ON, Immediate Release OFF, Hold Attack ~150 ms as the hold threshold) + Comparator + Flip-Flop + CV Switch. (Doug Krieger 5-module "Switcheroo" variant: Stompswitch + Out Switch + CV Delay + Flip-Flop + CV Invert.)
- **Chromatic sample playback:** Keyboard/MIDI note → Sampler speed/pitch; base pitch/speed offset **~−0.325** centers on C4 and prevents "bird shriek" transposition; Sampler speed/pitch spans 3.1%-3200% = −60 to +60 semitones ([Sampler/Sequencer Guide](https://cdn.shopify.com/s/files/1/0028/5462/files/ZOIA_4.0_Sequencer_Sampler_Guide_rev3.pdf?v=1727875139)).
- **Pitch-tracked guitar synth:** Audio In → Pitch Detector → Oscillator freq @100% (gate-threshold first for clean tracking); Value → Oscillator freq as a fixed interval offset (e.g. a 5th); Env Follower → VCA level.

## ZOIA vs Euroburo

- **ZOIA** = pedal: stereo audio I/O, two stompswitches (Bypass/Scroll), Control Port (MIDI/exp/CV/switch), microSD, internal patch slots.
- **Euroburo** = 34HP Eurorack module / optional desktop case (9-12 V center-negative, 300 mA): **no stompswitches** (Stompswitch module dropped from its menu in fw 2.30), **4 CV in / 4 CV out + 8 CV buttons**, 2 "sticky"/integrated pushbuttons, stereo 3.5 mm audio, **headphone out** (cloned from main out), Euroburo-specific CV voltage mappings + clock filters + A→C transpose ([Euroburo manual](https://images.equipboard.com/uploads/item/manual/97410/empress-zoia-euroburo-manual.pdf)).
- **Same firmware since fw 2.20.** A Euroburo patch on a pedal puts Euroburo modules on a "Euro Modules" page above page 0 — connect/edit but not move/copy/re-add. Euroburo bypass = **Shift + press the audio I/O buttons**. Integrated interface modules sit permanently near the jacks. Factory banks differ (fw-5 ZOIA set is guitar-centric; Euroburo has its own) ([changelog](https://cdn.shopify.com/s/files/1/0028/5462/files/zoia_changelog_74aa73a7-3b95-425b-ba10-baf85de31592.txt?v=1770216051)).

## The .bin Patch Format (community-reverse-engineered, NOT official)

Empress has stated they will not open the binary format; the following is from the meanmedianmoge `Binary Format.pdf` and the [mdouchement Go parser](https://github.com/mdouchement/zoia) — treat offsets as approximate and test edited patches on hardware. A patch is **little-endian, 4-byte words**, laid out (fw ≥1.10) as `[header][modules][#patch_cables][patch_cables][#pages][pages][per-module extra][padding]`; pre-1.10 patches omit the per-module "extra" (Extended Colours) block. The **header** = patch length (stored ×4 = a word count) + module count; **patch name is 15 chars max**. There is **no firmware-version field** — parsers detect <1.10 vs ≥1.10 by comparing running offset to patch length. Each **module** stores type/ID byte, color byte, page, **grid position (0-39 on the 8×5 grid)**, an 8-entry options array, parameters, and a trailing 15-byte name. Each **connection** stores source module+block, destination module+block, and a strength/gain scaled to roughly **−100…+12 dB**. Official user-facing workflow is far simpler: `.bin` files with a **three-digit numeric prefix** (= slot) copied to/from SD via Config ([manual](https://empresseffects.com/cdn/shop/files/ZOIA_User_Manual_rev02_web.pdf?v=9116714327727882529)).

## Staged Learning Plan

1. **Foundations (week 1):** read the manual with the device in front of you; install current firmware after backing up patches; keep the Module Index open; build a tremolo (LFO→VCA) and the mono synth voice from memory.
2. **Architecture fluency (weeks 2-4):** internalize the Tips doc on connection strength, CV summing, min/maxing, and `0.1 = 1 octave`; deconstruct three Patchstorage patches in the Librarian visualizer (Space Race, a groovebox, a reverb patch).
3. **Power use (month 2+):** build a generative patch (Random→Quantizer→Osc clocked by LFO), a multi-fx with stompswitch/UI-button pages in Performance Mode, and a MIDI/utility patch; keep CPU under ~70% via the DSP screen; organize a gig-ready bank in the Librarian. On Euroburo, set up clock filters before CV-heavy work.
