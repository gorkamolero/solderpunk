# Behringer Brains — Video & Media Learning Resources

Curated, verified video/media resources for learning the **Behringer Brains** Eurorack
macro-oscillator. Brains runs the Mutable Instruments **Plaits** DSP (15 Plaits engines +
Behringer-added engines: Supersaw, FM Drum, Cowbell, Tom, plus later BX7/DX7, TD-3 bassline,
Wave Generator and Vox additions). **Plaits content is directly relevant** because the shared
engines are bit-for-bit the same algorithms and the macro controls (HARMONICS / TIMBRE / MORPH)
behave identically. Each resource is tagged **[Brains]** or **[Plaits]**.

Verification note: YouTube watch/playlist pages render only footer/nav text to a fetcher (the
channel name and stats load client-side), so for many YouTube items the channel/title was
confirmed via search-result metadata and corroborating blog/forum pages rather than by reading
the live page. Each entry states exactly how it was verified. Items that could not be confirmed
to exist were discarded.
