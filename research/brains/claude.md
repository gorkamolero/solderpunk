# The Definitive Behringer Brains Reference & Mastery Guide

**Scope:** Behringer Brains is a 16 HP Eurorack macro-oscillator that wraps the open-source Mutable Instruments Plaits DSP (MIT-licensed code) in Behringer hardware, adding an OLED scope, a USB port, three LED-coloured banks, and Behringer-developed engines (BX7/DX7 FM, TD-3 Bassline, Wave Generator, Vox, Audio Scope). Because the shared engines run Plaits code, Plaits documentation is authoritative for them. Sources are cited inline; an annotated source list closes the guide.

---

## TL;DR
- Brains = a Plaits hardware clone with extras: the latest firmware (manual V5.0, 2024) advertises **24 synthesis engines** — the 15 Plaits-derived models plus Behringer's own Supersaw, FM Drum, Cowbell, Toms (original 2021 release = 20 engines) and the 2023 "Reloaded" engines BX7 (DX7 FM), Bassline (TD-3), Wave Generator and Vox, with Audio Scope as a 5th utility mode. For every shared engine, Harmonics/Timbre/Morph/Aux behave exactly as documented in the Plaits manual.
- The biggest "hidden" features are inherited Plaits button-combos: hold the **Bank** button + Timbre/Morph to set the LPG (VCFA↔VCA) and decay; hold the **Model** button + Harmonics to set the FREQ knob range/octave. Brains has **NO true MIDI port** — USB is class-compliant USB-MIDI used only for firmware/SysEx via SynthTribe; note control is CV/gate only.
- Known quirks: V/Oct calibration drifts (a ModWiggler user measured a Brains "out ~10 cent at 4.0018V"), the model-CV jack uses an unintuitive ±5 V map and changes lag triggers (delay the trigger), and Brains cannot run stock Plaits firmware (different hardware), so it never received Plaits' 8-engine 1.2 update.

## 1. Hidden Features & Menu/Easter-Egg Settings Most Owners Never Discover

Plaits was deliberately built with "no menu, no hidden settings, no easter eggs" — designer Émilie Gillet confirmed "nope" when asked whether one was hidden inside, on the MI forum ([modwiggler.com/forum/viewtopic.php?t=197383&start=50](https://modwiggler.com/forum/viewtopic.php?t=197383&start=50)). So the "hidden" features are really button-combo settings printed on the last page of the manual that most owners miss (a ModWiggler user noted the "hidden features are on the very last page of the Brains manual": [modwiggler.com/forum/viewtopic.php?t=249968&start=180](https://modwiggler.com/forum/viewtopic.php?t=249968&start=180)).

**Inherited from Plaits (button combos):**
- **LPG character (VCFA↔VCA):** On Brains, hold the **Bank** button and turn **Timbre** — fully CW = VCA, fully CCW = true low-pass gate. On Plaits, the same is done by holding the *first* model button and turning Timbre. ([Brains manual](https://manuals.plus/brains/brains-high-resolution-multi-engine-oscillator-module-manual); [Plaits manual](https://pichenettes.github.io/mutable-instruments-documentation/modules/plaits/manual/)). Plaits-inherited behaviour, remapped to the dedicated Bank button.
- **LPG ring/decay time:** Hold Bank (Brains) / first button (Plaits) and turn **Morph**; shown by 1–4 yellow LEDs. Because it is an LPG, "a unique lingering sound will remain even if the decay is shortened" ([clockfacemodular.com](https://clockfacemodular.com/en/products/mutable-instruments-plaits)).
- **FREQ knob range / octave:** Hold **Model** (Brains) / second button (Plaits) and turn **Harmonics**. 1 LED = C0 ±7 semitones, 2 = C1 ±7 … 8 = C7 ±7; all LEDs lit = full 8-octave range C0–C8 ([Brains manual](https://manuals.plus/brains/brains-high-resolution-multi-engine-oscillator-module-manual); [Plaits manual](https://pichenettes.github.io/mutable-instruments-documentation/modules/plaits/manual/)). This is the #1 fix for "Brains is too high / clicking" — a clicking sound means it's set to the lowest range ([Plaits manual, "Common issues"](https://pichenettes.github.io/mutable-instruments-documentation/modules/plaits/manual/)).
- **Plaits-only firmware extras NOT in Brains:** v1.1 added a colour-blind mode (power on holding right button) and an LFO frequency range ("chasing lights" pattern, ~0.015 Hz–16 Hz); v1.2 added an octave frequency mode and an alternate previous/next model selection by a *very short* simultaneous press of both buttons ([pichenettes.github.io/.../plaits/firmware/](https://pichenettes.github.io/mutable-instruments-documentation/modules/plaits/firmware/)). These are part of the Plaits 1.2 update that Brains never received.

**Brains-specific "hidden" behaviours:**
- **Internal envelope normalled to CV inputs:** When a Timbre/Morph/FM CV input is unpatched and Trig is patched, the attenuverter sets how much of the internal decay envelope modulates that parameter ([Brains manual](https://manuals.plus/brains/brains-high-resolution-multi-engine-oscillator-module-manual); [Plaits manual](https://pichenettes.github.io/mutable-instruments-documentation/modules/plaits/manual/)). Reset attenuverters to 12 o'clock after unpatching, or the envelope "takes over."
- **Drum/physical models bypass the LPG:** For modal/percussion engines the internal LPG is disabled, Trig triggers synthesis, and the **Level** input becomes an accent control ([Plaits manual](https://pichenettes.github.io/mutable-instruments-documentation/modules/plaits/manual/)).
- **Bass-drum/FM-drum drone trick:** With nothing patched to Trig, the analog bass-drum model produces a continuous tone whose amplitude is still modulated by Morph ([Plaits manual](https://pichenettes.github.io/mutable-instruments-documentation/modules/plaits/manual/)) — a usable drone/sine source.

## 2. Firmware Notes, Version Gems & How Brains Diverges from Plaits

**Plaits firmware lineage (authoritative for shared engines):**
- v1.0 initial; v1.1 colour-blind + LFO range; **v1.2 (final)** added a second bank of 8 engines (Classic waveshapes+filter; Phase distortion; 3× six-operator FM with 32 DX7-style presets; Wave terrain; String machine; Chord/arpeggio four-square-voice), an online editor + DX7 SysEx/wavetable/wave-terrain custom loading, responsiveness fixes, and improved wavetable band-limiting ([pichenettes.github.io/.../plaits/firmware/](https://pichenettes.github.io/mutable-instruments-documentation/modules/plaits/firmware/)).

**Brains firmware lineage:**
- **Original (2021):** 20 engines = 15 Plaits-derived models + Behringer's Supersaw, FM Drum, Cowbell, Toms; OLED scope; USB. Manual V1.0 ([synthanatomy.com/2021/06/...](https://synthanatomy.com/2021/06/behringer-brains-macro-oscllator-with-15-mutable-instruments-plaits-algorithms.html); [gearnews.com](https://www.gearnews.com/behringer-brains-multi-engine-eurorack-oscillator/)).
- **"Reloaded" (March 2023):** added 5 modes — **BX7** (DX7-compatible FM, 32 patches, SysEx-loadable via SynthTribe), **Bassline** (TD-3/TB-303 emulation), **Wave Generator** (bitcrush/sample-rate), **Vox** (vocal/formant morphing), **Audio Scope** (turns the OLED into an oscilloscope, signal in via V/Oct) ([synthtopia.com/.../behringer-brains-reloaded-adds-5-new-modes/](https://www.synthtopia.com/content/2023/03/02/behringer-brains-reloaded-adds-5-new-modes/); [musictech.com/news/gear/behringer-brains-reloaded/](https://musictech.com/news/gear/behringer-brains-reloaded/)). The screen now shows the model name ([modwiggler.com/forum/viewtopic.php?t=271793](https://modwiggler.com/forum/viewtopic.php?t=271793)).
- **Latest (manual V5.0, 2024):** "24 Synthesis Engines, 96 kHz, OLED Oscilloscope" ([manualsfile.com/product/k5v2tkbnnh1.html](https://manualsfile.com/product/k5v2tkbnnh1.html)). Behringer's official breakdown ([behringer.com/product/0720-ABP](https://www.behringer.com/en/products/0720-ABP); [behringersound.com/product/brains/](https://behringersound.com/product/brains/)): "10 synth engines: Virtual Analog, Waveshaper, FM, Grains, Additive, Chords, Speech, Karplus, Hypersaw and Wavetable · 10 percussion and noise engines: Rain, Noise, Dust, Modal Strings, FM Drum, Bass, Snare, Hi Hat, Cowbell and Tom · 4 extended engines: DX7, TD-3 Bassline, Wave Generator and Vox," with Audio Scope as the 5th Reloaded utility.

**Critical divergences from Plaits:**
1. **Different engine set.** Brains did NOT get Plaits' 1.2 bank (the MI 1.2 code wasn't open-source at release); Behringer wrote its own BX7/Bassline/Wave Generator/Vox instead ([synthanatomy.com/2023/03/...](https://synthanatomy.com/2023/03/behringer-brains-reloaded-new-update-adds-5-engines-fm-synth-td-3.html)). The BX7's two extra parameters (fixed LFO to pitch, fixed LFO to level) differ from MI's index/time-travel approach ([modwiggler.com/forum/viewtopic.php?t=249968&start=125](https://modwiggler.com/forum/viewtopic.php?t=249968&start=125)).
2. **Hardware.** Brains is 16 HP vs Plaits' 12 HP, draws more current, runs a more powerful CPU with more flash, and — per Sound On Sound — "increased the output sample rate to 96kHz as opposed to 48kHz on the Plaits, although the Braids was 96kHz" ([soundonsound.com/reviews/behringer-brains](https://www.soundonsound.com/reviews/behringer-brains)). Brains uses three LED-coloured banks (red/green/yellow) vs Plaits' two (green/red).
3. **Firmware delivery.** Brains updates via **USB + SynthTribe app**; Plaits updates via audio injection into a CV input. Brains **cannot** run stock Plaits firmware (different hardware) ([equipboard.com/items/behringer-brains](https://equipboard.com/items/behringer-brains); [kvraudio.com/forum/viewtopic.php?t=566552&start=15](https://www.kvraudio.com/forum/viewtopic.php?t=566552&start=15)).
4. **Scope limitation.** The Brains scope shows the internally generated signal (and external audio only in the dedicated Audio Scope mode via V/Oct). Sound On Sound found it "works really well and is a great companion to droning, although when you get to playing, sequencing or triggering sounds it does feel a bit sluggish" ([soundonsound.com/reviews/behringer-brains](https://www.soundonsound.com/reviews/behringer-brains)).
5. **Calibration UI.** Brains calibration uses Bank+Model buttons with 1 V/3 V reference points ([Brains manual](https://manuals.plus/brains/brains-high-resolution-multi-engine-oscillator-module-manual)); Plaits uses both buttons.

**License/attribution context:** Plaits code is MIT-licensed (permissive); the hardware is CC-BY-SA-3.0. Brains is widely discussed as a legal-but-controversial clone; Behringer added its own engines rather than releasing the new modes as open source ([synthtopia.com/.../behringer-brains-reloaded-adds-5-new-modes/](https://www.synthtopia.com/content/2023/03/02/behringer-brains-reloaded-adds-5-new-modes/)).

## 3. The Engine Atlas — Harmonics / Timbre / Morph / Aux / CV per Engine

For every shared engine the behaviour below is **Plaits-inherited** ([Plaits manual](https://pichenettes.github.io/mutable-instruments-documentation/modules/plaits/manual/)) and corroborated by the Brains "Waveform Parameters" table ([Brains manual](https://manuals.plus/m/cfe19a8d9d45e74285a5f29e10f1c063fd3b102df47ebe1d661165f2c4032c7a)). Behringer-added engines are flagged **[Behringer]**.

### SYNTH / PITCHED (Bank A / red)

1. **Virtual Analog (pair of classic waveforms)** — Two detuned VA waves. HARMONICS: detuning between the two waves. TIMBRE: variable square (narrow pulse→full square→hardsync formants). MORPH: variable saw (triangle→saw with widening notch, Braids' CSAW). **AUX: sum of two hardsync'd waveforms.** Tip: a narrow pulse or wide notch = silence — use it to mute one oscillator.
2. **Waveshaping** — Asymmetric triangle through waveshaper + wavefolder. HARMONICS: waveshaper waveform. TIMBRE: wavefolder amount. MORPH: waveform asymmetry. **AUX: variant with another wavefolder curve.**
3. **2-Operator FM** — Two sines modulating each other's phase. HARMONICS: frequency ratio. TIMBRE: modulation index. MORPH: feedback (op2→own phase past 12 o'clock = rough; op1's phase before 12 o'clock = chaotic). **AUX: sub-oscillator.** Tip: MORPH fully CCW = Braids WTFM, fully CW = Braids FBFM, noon = gentle FM.
4. **Grains / Formant (two formants)** — VOSIM/Pulsar/Grainlet/Casio-CZ-style formants. HARMONICS: ratio between formant 1 and 2. TIMBRE: formant frequency. MORPH: formant width/shape. **AUX: windowed-sine filtered-waveform simulation; Harmonics selects filter type (peaking, LP, BP, HP).**
5. **Harmonic / Additive** — 24 harmonically-related sines. HARMONICS: number of spectral bumps. TIMBRE: index of most prominent harmonic (≈ BP cutoff). MORPH: bump shape (flat/wide→peaked/narrow ≈ BP resonance). **AUX: variant using only Hammond-organ drawbar harmonics (ratios 1, 2, 3, 4, 6, 8, 10, 12).**
6. **Wavetable** — Four banks of 8×8 waves. HARMONICS: bank select. TIMBRE: row index (sorted by brightness). MORPH: column index. **AUX: low-fi (5-bit) output.** Banks: A additive/drawbar; B formant/waveshaping; C Shruthi/Ambika ROM tables; D random permutation.
7. **Chords** — Four-note chords via VA or wavetable oscillators. HARMONICS: chord type. TIMBRE: chord inversion/transposition. MORPH: waveform (first half = string-machine drawbar waves, second half = 16-wave wavetable). **AUX: root note of the chord.** Stock chord order across Harmonics: **octave, fifth, sus4, m, m7, m9, m11, 6/9, M9, M7, M** ([plaits_quickstart.pdf](https://pichenettes.github.io/mutable-instruments-documentation/modules/plaits/downloads/plaits_quickstart.pdf)).
8. **Speech / Vowel** — Formant filter + SAM + LPC synthesis. HARMONICS: crossfades formant→SAM→LPC vowels, then several banks of LPC words. TIMBRE: "species" (Daleks→chipmunks). MORPH: phoneme/word-segment selection. **AUX: unfiltered vocal-cords signal.** Tip: with Harmonics past 11 o'clock, patch Trig to trigger word utterances, FM attenuverter for intonation, Morph attenuverter for speed.

**[Behringer] Supersaw / Hypersaw + Karplus** — Sound On Sound: "The Supersaw is really nice especially when running free as a regular oscillator rather than being triggered through the LPG. The sound is thick and luscious, and you can dial in a sub-oscillator, further harmonics, increase the waveform count and do some detuning" ([soundonsound.com/reviews/behringer-brains](https://www.soundonsound.com/reviews/behringer-brains)). **AUX: "Copy of Out 1"** for Supersaw and Wavetable ([Brains manual](https://manuals.plus/m/cfe19a8d9d45e74285a5f29e10f1c063fd3b102df47ebe1d661165f2c4032c7a)). MORPH on Supersaw ≈ sub-oscillator level; decay-time on Karplus.

### NOISE / PERCUSSION (Bank B / green)

9. **Granular Cloud (Rain on Brains)** — 8 enveloped saws. HARMONICS: pitch randomization. TIMBRE: grain density. MORPH: grain duration/overlap. **AUX: variant with sine oscillators.**
10. **Filtered Noise (Noise)** — Variable-clock white noise → resonant filter; cutoff tracks FREQ + V/Oct. HARMONICS: filter response LP→BP→HP. TIMBRE: clock frequency. MORPH: resonance. **AUX: variant with two band-pass filters, separation set by Harmonics.**
11. **Particle Noise (Dust)** — Dust through all-pass/band-pass networks. HARMONICS: frequency randomization. TIMBRE: particle density. MORPH: filter type (reverberating all-pass before noon → resonant BP after). **AUX: raw dust noise.**
12. **Inharmonic String / Modal (Modal Strings)** — Mini-Rings. HARMONICS: inharmonicity/material. TIMBRE: excitation brightness/dust density. MORPH: decay (energy absorption). **AUX: raw exciter signal.**
13. **Analog Bass Drum** — Bridged-T network + shaped pulse. HARMONICS: attack sharpness/overdrive. TIMBRE: brightness. MORPH: decay. **AUX: FM-triangle-VCO bass-drum variant.** Untriggered = continuous tone (drone).
14. **Analog Snare Drum** — Bridged-T networks per shell mode + BP noise. HARMONICS: harmonic/noise balance. TIMBRE: mode balance. MORPH: decay. **AUX: FM sine-VCO pair + HP noise variant.**
15. **Analog Hi-Hat** — Square-osc metallic tone + clocked noise → HPF → VCA. HARMONICS: metallic/noise balance. TIMBRE: HPF cutoff. MORPH: decay. **AUX: variant using 3 ring-modulating square-osc pairs + clean VCA.**

**[Behringer] FM Drum, Cowbell, Toms** — Sound On Sound: "The FM Drum has got a good range of tones from zappy to squelchy. The Cowbell is more reminiscent of Super Mario arcade sounds than percussion, but the Toms algorithm has some interesting grit to it when pushed" ([soundonsound.com/reviews/behringer-brains](https://www.soundonsound.com/reviews/behringer-brains)). Morph = decay time for these.

### [Behringer] Extended (Yellow bank) — from Brains V5.0 "Waveform Parameters" table ([manualsfile.com](https://manualsfile.com/product/k5v2tkbnnh1.html))

- **BX7 (DX7 FM):** 32 DX7-compatible patches. **Timbre = Vibrato, Harmonics = Preset selection, Morph = Tremolo, Level = Velocity.** An enveloped synth voice that must be triggered via Trig.
- **Bassline (TD-3):** TB-303 emulation. **Timbre = Cutoff, Harmonics = Resonance/distortion, Morph = Env mod/Decay, Level = Accent.** Trigger via Trig.
- **Wave Generator:** **Timbre = Waveform, Harmonics = Bit Crush, Morph = Sample Rate, Level = Level.**
- **Vox:** **Timbre = Formant shift, Harmonics = Reso, Morph = Blend Vowels, Level = Level.**
- **Audio Scope:** routes external audio (via V/Oct) to the OLED as a basic oscilloscope; not a sound generator ([synthtopia.com](https://www.synthtopia.com/content/2023/03/02/behringer-brains-reloaded-adds-5-new-modes/)).

**Aux/Out 2 general principle:** Out 2 carries "an alternate or variant of the Out 1 signal" (Brains manual); Plaits: "the AUX output carries a variant, sidekick, or by-product of the main signal." Community tip: pan OUT/AUX hard L/R for instant stereo, or crossfade between them ([musicradar.com/reviews/mutable-instruments-plaits](https://www.musicradar.com/reviews/mutable-instruments-plaits); [modwiggler.com/forum/viewtopic.php?t=214612](https://modwiggler.com/forum/viewtopic.php?t=214612)).

**Global CV / I/O (Brains, V5.0 spec, [manualsfile.com](https://manualsfile.com/product/k5v2tkbnnh1.html)):** Timbre CV ±8 V (50k); Harmonics CV ±5 V (100k); Freq CV ±8 V (50k); Morph CV ±8 V (50k); Model CV ±5 V (100k); V/Oct −3 to +7 V (100k); Level 0 to +8 V (50k); Trig 0 to +8 V (50k). Out 1 / Out 2: 3.5 mm TS, DC-coupled, 1k, max 6.2 V. Plaits' published ranges match ([pichenettes.github.io/.../plaits/](https://pichenettes.github.io/mutable-instruments-documentation/modules/plaits/)).

## 4. MIDI / CV Control Tricks

- **No hardware MIDI.** Brains has only USB (class-compliant USB-MIDI) and CV. The USB port is "for firmware updates" and SynthTribe; pitch/gate must come from CV. To play it from a MIDI keyboard, use a MIDI-CV converter into V/Oct and Trig ([modwiggler.com/forum/viewtopic.php?t=267303](https://modwiggler.com/forum/viewtopic.php?t=267303); [modwiggler.com/forum/viewtopic.php?t=266609](https://modwiggler.com/forum/viewtopic.php?t=266609)).
- **USB-MIDI SysEx for BX7:** You can send DX7/DX7II SysEx banks over USB-MIDI — one ModWiggler user uploaded banks from an Android phone via the DX-7II Librarian web app, in either mode, bypassing SynthTribe ([modwiggler.com/forum/viewtopic.php?p=4268139](https://www.modwiggler.com/forum/viewtopic.php?p=4268139)). SysEx overwrites the 32 BX7 presets.
- **BX7 velocity:** BX7/Bassline are enveloped synth voices; for DX7-like dynamics, feed a velocity CV into the **Level** input — a Sweetwater reviewer reserved one sequencer channel for velocity to make BX7 "sound reasonably like a DX7, albeit a monophonic one" ([sweetwater.com](https://www.sweetwater.com/store/detail/Brains--behringer-brains-multi-engine-oscillator-eurorack-module/reviews)).
- **Model-CV as a drum sequencer / kit:** Patch CV to the **Model** jack (±5 V) and assign notes/voltages to engines for a full drum kit. The model→voltage map is non-linear; a ModWiggler user measured: Toms 1.578, Cowbell 1.417, Hi-Hat 1.238, Snare 0.872, Bass 0.677, FM Drum 0.492, Modal 0.301, Dust −0.056, Noise −0.424, Rain −0.626, WT −0.801, Supersaw −1.294, Karplus −1.518, Speech −1.847, Chords −2.086, Additive −2.136, Grains −2.454, FM2 −2.64, Waveshaping −3.014, VA −3.276 ([modwiggler.com/forum/viewtopic.php?t=249968&start=150](https://modwiggler.com/forum/viewtopic.php?t=249968&start=150)). Model input only affects red/green engines.
- **Quirk — delay the trigger:** Model changes don't happen instantly; if a model-change CV and a trigger arrive together, the trigger plays the old/in-between model. Solution: delay the trigger slightly; bigger model jumps need a longer delay ([modwiggler.com/forum/viewtopic.php?t=249968&start=175](https://www.modwiggler.com/forum/viewtopic.php?t=249968&start=175)).
- **Sample-and-hold on Model:** Trig samples-and-holds the Model CV (manual), so per-note model switches are stable when clocked.
- **Self-patching / audio-rate FM:** Patch OUT or AUX back into FM, Timbre, or Morph for "interesting/bonkers/terrifying" results ([modwiggler.com/forum/viewtopic.php?t=197383&start=850](https://modwiggler.com/forum/viewtopic.php?t=197383&start=850)). Note CV inputs are band-limited (DC–~2 kHz), so audio-rate through-zero FM is limited vs analog; for true FM, feed audio into V/Oct instead. Patch both outputs into Warps for hybridization ([pichenettes.github.io/.../plaits/](https://pichenettes.github.io/mutable-instruments-documentation/modules/plaits/)).

## 5. Patch Recipes (Exact Engine + Macro + Routing)

All settings reference Brains controls; behaviours are Plaits-inherited unless flagged. Knob positions are starting points.

- **Deep bass:** Engine **2-Op FM** (or Virtual Analog). Set FREQ range to 1–2 LEDs (low octave: hold Model + Harmonics). Harmonics ~9 o'clock (low ratio), Timbre low–mid (index), Morph at noon. Patch Trig → internal LPG; Level for accent. "No real bass" complaints almost always trace to the wrong FREQ range — set it low first ([modwiggler.com/forum/viewtopic.php?t=271486](https://modwiggler.com/forum/viewtopic.php?t=271486)).
- **Acid bass:** Engine **Bassline [Behringer]** — Timbre=Cutoff, Harmonics=Resonance/distortion, Morph=Env mod/Decay; trigger via Trig, accent via Level ([manualsfile.com](https://manualsfile.com/product/k5v2tkbnnh1.html)). Sequence pitch via V/Oct.
- **Lead:** Engine **Waveshaping** or **Supersaw [Behringer]**. Run Supersaw *free* (no Trig) for a thick detuned lead; dial sub-osc via Morph, harmonics/detune via Harmonics ([soundonsound.com](https://www.soundonsound.com/reviews/behringer-brains)). Waveshaping: Harmonics=waveshape, Timbre=fold amount for screaming leads.
- **Lush chords / pad:** Engine **Chords**. Harmonics selects chord type (oct→M); Timbre = inversion/transposition; Morph sweeps string-machine→wavetable waveforms. Crossfade OUT (chord) and AUX (root) for movement ([musicradar.com](https://www.musicradar.com/reviews/mutable-instruments-plaits)).
- **Drone / generative:** Engine **Bass Drum** untriggered = continuous tone, amplitude via Morph ([Plaits manual](https://pichenettes.github.io/mutable-instruments-documentation/modules/plaits/manual/)). Or **Additive** with slow Harmonics/Morph LFOs. Use Marbles/random CV → Harmonics/Timbre/Morph; LFO on Model for evolving timbres.
- **Drums (full kit from one module):** Bank B percussion (Modal/FM Drum/Bass/Snare/Hi-Hat/Cowbell/Toms). Trig triggers synthesis, Level = accent (LPG bypassed). For a sequenced kit, drive Model CV with per-step voltages (see §4 map) and delay the trigger.
- **Speech/robot voice:** Engine **Speech** or **Vox [Behringer]**. Speech: Harmonics past 11 o'clock for words, Trig to utter, FM attenuverter = intonation, Morph attenuverter = speed. Vox: Timbre=formant shift, Harmonics=reso, Morph=vowel blend.
- **Textures:** Engine **Dust** (raw dust on AUX) or **Noise** (BP-pair variant on AUX); HARMONICS for filter character; pair with reverb. Modal Strings can be excited by external audio (Rings-style) for resonator textures.
- **Stereo:** Any engine — OUT to L, AUX to R; or crossfade with a crossfader/VCA ([musicradar.com](https://www.musicradar.com/reviews/mutable-instruments-plaits); [modwiggler.com/forum/viewtopic.php?t=214612](https://modwiggler.com/forum/viewtopic.php?t=214612)).

## 6. Sample / Wavetable / Preset Resources

- **BX7 / DX7 patches:** Load 32-voice DX7 `.syx` SysEx via SynthTribe (USB) — overwrites BX7 memory. Step-by-step from a Sweetwater owner: download SynthTribe (Windows reported more reliable than Mac), connect USB, upload the `.syx`, then select voices with the Harmonics knob ([sweetwater.com](https://www.sweetwater.com/store/detail/Brains--behringer-brains-multi-engine-oscillator-eurorack-module/reviews)). Alternative: send banks via USB-MIDI from the DX-7II Librarian web app on Android ([modwiggler.com/forum/viewtopic.php?p=4268139](https://www.modwiggler.com/forum/viewtopic.php?p=4268139)).
- **No user wavetable/sample loading** for the oscillator engines on Brains (unlike Plaits 1.2's online editor, which Brains never received). The Wave Generator engine offers built-in waveforms with bit-crush/sample-rate controls but no user-sample import.
- **SynthTribe app** (Behringer, Mac/Windows) handles firmware updates and BX7 SysEx; reach it from the Brains product page Downloads ([sweetwater.com/sweetcare/articles/getting-started-with-behringer-synthtribe/](https://www.sweetwater.com/sweetcare/articles/getting-started-with-behringer-synthtribe/)).
- **Plaits 1.2 online editor** (for actual Plaits, not Brains): [pichenettes.github.io/plaits-editor/](https://pichenettes.github.io/plaits-editor/).

## Caveats & Contradictions

- **Engine count varies by source/firmware.** Behringer marketing has said 20, 24, and "25 synth models"; the latest manual (V5.0, 2024) and retailers say **24 engines** ([manualsfile.com](https://manualsfile.com/product/k5v2tkbnnh1.html); [behringersound.com](https://behringersound.com/product/brains/)). Honest reading: 20 sound engines at launch + 4 extended (BX7, Bassline, Wave Generator, Vox) = 24, with Audio Scope a utility mode (counting it yields "25"). Older 20-page manuals use "Bank A/B"; newer ones use red/green/yellow banks.
- **AUX cell wording for Behringer's drum engines** ("Alternate FM drum/cowbell/tom models" etc.) comes from a Behringer installation-guide fragment and could not be re-confirmed verbatim from currently-accessible mirrors; the Plaits-derived AUX behaviours ARE confirmed verbatim.
- **Tuning/calibration.** Multiple owners report Behringer Eurorack oscillators (incl. Brains) tracking off near 4 V despite "factory calibrated" claims; one ModWiggler user found his "Brains was out ~10 cent at 4.0018V so it needs calibration" — but also flagged a measurement red herring: "When I hooked the big Fluke up, it showed 4.2V rather than the 4.00V reported on the red DVM" ([modwiggler.com thread t=260817](https://modwiggler.com/forum/viewtopic.php?t=260817)). Calibrate with a trusted DVM/tuner using the Bank+Model 1 V/3 V routine; verify A2=110 Hz, A3=220, A4=440, A5=880 (Brains manual).
- **"High-Resolution" garbled manual.** One mirror ([manuals.plus/brains/...](https://manuals.plus/brains/brains-high-resolution-multi-engine-oscillator-module-manual)) mixes in joystick/PAGE/SAVE/"factory program 32" text that does not match Brains hardware (no joystick) — likely cross-contaminated from another product's manual; treat those specific lines with caution.
- **Marketing language flagged.** Sweetwater's "neural network" copy is marketing, not a literal description; "24 engines" on the box counts the extended modes. No precise published mA figure was found to confirm exactly how much more current Brains draws than Plaits (community consensus: roughly double).
